<h1>Dashtro - 3D dungeon Crawler Roguelike</h1>

This is a game focused on fast and fluid movement where the player clears rooms of opponents until meeting the final boss.

Game was built from scratch in Unity/C#

<h3>Features</h3>
<ul>
  <li>Dash Ability that resets on kill which rewards fast and aggressive playstyles</li>
  <li>Custom boss encounter with stages</li>
  <li>In game shop</li>
  <li>Dark atmospheric lighting</li>
</ul>
